# First Step Beginners Flyer Research

This repository is a portable record and reproducible working environment for
revising the First Step Beginners AA Group flyer in GitHub Codespaces with the
Codex CLI.

It preserves:

- the three original supplied images;
- four successive flyer drafts that were available in the ChatGPT workspace;
- the chronological design and copy decisions;
- the current authoritative specification, including unresolved questions;
- a reusable method for recording future terminal/Codex sessions safely.

No new flyer is generated by this starter bundle. The next design revision
should begin only after the changed entrance information is documented.

## Start in GitHub Codespaces

Open this repository in a Codespace. In the Codespaces terminal, install and
authenticate Codex before recording:

```sh
curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex login --device-auth
codex login status
```

Then start the terminal recorder:

```sh
./scripts/start-session.sh
```

The command opens a recorded shell. From inside that shell, start Codex:

```sh
codex
```

When finished, leave Codex and then type `exit` once more to close the recorded
shell. The raw transcript is written under `sessions/raw/` and is intentionally
ignored by Git. Review and redact it before placing any portion in
`sessions/published/`.

## Read first

1. `docs/PROMPT-RECORD.md` — chronological record of the work to date.
2. `docs/ORIGINAL-COPY.md` — original text retained before later reductions.
3. `docs/CURRENT-SPEC.md` — the latest consolidated flyer requirements.
4. `docs/CODESPACES-RECORDING.md` — exact recording and publication procedure.
5. `docs/OPENAI-CODEX-NOTES.md` — account/authentication boundary and sources.
6. `docs/GITHUB-CODESPACES-IMPORT.md` — browser-only repository setup.
7. `AGENTS.md` — standing instructions for Codex or another coding agent.
8. `PLAN.md` — the proposed next steps and definition of done.

## Research principle

The public record should be reproducible, but it should not be a blind dump of
terminal output. Keep raw evidence private, publish reviewed Markdown notes,
and let Git commits preserve the exact file changes.
