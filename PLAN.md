# Project Plan

## Goal

Produce a corrected, legible, reproducible, print-ready 8.5-by-11-inch flyer
and publish a useful research record of the agent-assisted process.

## Work sequence

- [ ] Obtain and document the changed entrance information.
- [ ] Resolve the footer contact-information question recorded in
      `docs/CURRENT-SPEC.md`.
- [ ] Select the best draft only as a visual reference; retain the original
      sign, entrance photograph, and map/guide as source evidence.
- [ ] Create an editable canonical flyer in SVG or HTML/CSS.
- [ ] Implement the approved copy and visual hierarchy.
- [ ] Export a US-Letter PDF and a 2550-by-3300 PNG.
- [ ] Visually inspect the full page and every small-text region.
- [ ] Print a physical proof and check reading size, margins, and contrast.
- [ ] Record findings and corrections in a reviewed session report.
- [ ] Commit and push only after secret and privacy review.

## Definition of done

The work is done when the factual entrance information is confirmed, all copy
matches the approved specification, the door and guide remain useful, every
line is legible on a physical letter-size print, the source can be regenerated
from the repository, and the public session report contains no secrets or
unreviewed personal information.
